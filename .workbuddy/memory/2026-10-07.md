**关键技术决策**
- **不引入 `motion`**：全部动效用 CSS 过渡/关键帧 + 少量 `requestAnimationFrame`（只用于进度动画，原项目也是手写 rAF）。
- **主题走 Context**：原项目靠全局 `setGlobalShape` + `ThemeContext`；这里 `Md3eProvider` 统一管理并同时调用 `setGlobalShape`，保证 `scaleR` 在渲染辅助函数里也拿到正确刻度。
- **组件是受控/非受控双模式**（`value` / `defaultValue` 同存），Chip/Switch/Checkbox/Slider/Select 都支持。
- 图标走 Google Fonts 的 `Material Symbols Rounded` 可变字体（`@import` 在 `md3e.css` 顶部），用连字渲染。

**验证**：`tsc --noEmit` 全绿；Vite dev 下所有模块 200 且无 transform 错误。

**注意**：`vite.config.ts` 未改动，`demo.html` 只在 `vite dev` 下可访问；`npm run build` 仍只打包 `index.html`（不影响 Tauri）。
